# Skill: /woo-styles

WooCommerce animation CSS that matches the site's fx-* animation system.

## How to use

> /woo-styles — shop grid: card hover lift, slide-up add-to-cart button
> /woo-styles — product page: gallery zoom, pulsing add-to-cart
> /woo-styles — cart: stagger line items on load
> /woo-styles — full WooCommerce stylesheet

## What you get

CSS scoped to .woocommerce (only loads on shop pages).
Paste into assets/css/components.css in your child theme.

Covers: product card hover effects, image zoom, add-to-cart button states,
cart line item animations. All reduced-motion and touch-device safe.
